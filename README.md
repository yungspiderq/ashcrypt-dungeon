# Ashcrypt · Пепельный склеп

Под склепом спрятана Пепельная печать. Каждое убийство заряжает её, а когда заряд полон, можно обжечь всех врагов поблизости и уничтожить летящие снаряды. Зачищай комнаты, меняй экипировку по ходу забега и выбирай, как усилить Печать перед следующим этажом.

[Играть онлайн](https://yungspiderq.github.io/ashcrypt-dungeon/) · [Скачать релиз](https://github.com/yungspiderq/ashcrypt-dungeon/releases/latest)

## Подземелье

- Пять этажей по пять комнат. Схема переходов и добыча меняются с каждым забегом.
- Три вида обычных врагов и два босса. Перед ударами враги показывают опасную область.
- Оружие, доспехи и талисманы четырёх редкостей. Ненужную экипировку можно разобрать в прах.
- Семь усилений Печати. На каждом спуске предлагаются три случайных варианта. Один бесплатный, остальные можно открыть за прах.
- Сенсорное управление и автосохранение забега в браузере.

## Управление

| Действие | Клавиши |
| --- | --- |
| Переместиться | WASD или стрелки |
| Ударить | Пробел или щелчок в сторону цели |
| Уклониться рывком | Shift |
| Высвободить Печать при полном заряде | Q |
| Подобрать добычу или пройти через дверь | E рядом с целью |
| Выпить зелье | 1 |
| Поставить игру на паузу | Esc |

Для запуска офлайн распакуй `Ashcrypt-v1.0.0.zip` и открой `index.html`. Игра использует HTML, CSS, JavaScript и Canvas. Все игровые файлы входят в архив.
